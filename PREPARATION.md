# Canto Connector — Preparation

**Category:** C43. Digital Asset Management (DAM)  
**Vendor URL:** https://canto.com  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Canto** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C43. Digital Asset Management (DAM)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **фоторедактор** сталкивается с задачей: **структурирование корпоративного фото- и видео-банка, контроль прав доступа и быстрый поиск по тегам**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Canto переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **фоторедактор, менеджер по коммуникациям, PR-специалист**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `навигация по альбомам Canto -> выбор группы изображений -> генерация брендовой ссылки для передачи партнерам`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Canto.
